# TheOperator

Внешняя камера как самостоятельный плагин Unreal Engine: композиция кадра, переезды между камерами,
выбор держателя вида, линза, коллизия, репетиция в редакторе.

**Кода здесь пока нет.** В репозитории лежит документация, с которой плагин начинается.

## Что в этих документах

Три файла в корне — описание камеры проекта **One Way Home**, замеренное по его рабочей ветке. Это
ИСТОЧНИК, с которого снимается плагин, а не спецификация того, что здесь будет:

| Документ | О чём |
| --- | --- |
| [Camera.md](Camera.md) | Как устроена система целиком: из чего собрана, что дизайнер ставит на уровень, какие параметры на чём крутятся, что происходит в момент перехода с одной камеры на другую |
| [Camera-HowTo.md](Camera-HowTo.md) | Короткая инструкция: поставить камеру на уровень и получить кадр |
| [Camera-DemoScene.md](Camera-DemoScene.md) | Демо-сцена, на которой всё это показано в работе |

Картинки, на которые они ссылаются, — в `images/camera/`.

## Чем плагин будет отличаться от источника

- **Рельс — один из режимов следования, а не суть рига.** В One Way Home имя класса, зона-как-корень и
  обязательный сплайн приезжают из сайдскроллера; здесь рельс встаёт в один ряд с фиксированной точкой,
  орбитой и спринг-армом.
- **Ноль зависимостей от чужого проекта.** Ни одного `/Game/`-литерала, ни одного модуля игры в
  `.Build.cs` — самодостаточность здесь свойство продукта, а не удобство.
- **Таксономия своя.** Имена типов и папок переименовываются при переносе; читать документы стоит по
  смыслу, а не по идентификаторам.

One Way Home остаётся на своей копии кода. Значит правка камерного правила делается дважды — это
признанный долг, а не недосмотр.
